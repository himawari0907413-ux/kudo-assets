広告について

このサイトはアフィリエイトプログラム（楽天アフィリエイトなど）に参加しています。紹介している宿のリンクから予約されると、運営者に紹介料が支払われることがあります。予約の料金が高くなることはありません。

広告を含むページには、ページの上部に「PR」と表示しています。

掲載している情報について

口コミの集計は、楽天トラベルの口コミを話題ごとに数えて要約したものです。口コミの本文は引用していません。宿の情報は楽天トラベルと各宿の公式サイトで確認した時点のものです。料金・空室・設備は変わることがあるので、予約の前に予約ページで確認してください。

プライバシーポリシー

アクセス解析

ページの閲覧数を知るために Cloudflare Web Analytics を使っています。Cookie は使わず、個人を特定する情報は集めていません。

予約ボタンのクリック

どの宿の予約ボタンが押されたかを知るために、押された日付・宿・ボタンの位置だけを記録しています。個人を特定する情報や IP アドレスは記録していません。

リンク先のサービス

リンク先（楽天トラベルなど）では、紹介料の計算のために各サービスが Cookie を使うことがあります。詳しくは各サービスのプライバシーポリシーをご覧ください。

免責事項

掲載内容はできるだけ正確にしていますが、内容を保証するものではありません。リンク先での予約・利用については、各サービスの規約に従ってください。
